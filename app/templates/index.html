Setup Guidance

Cost rules, security boundaries, and licensing

Security & Storage Guarantee

Credentials are saved locally using the Windows Credential Manager service. They are never sent outside localhost, never printed to terminal logs, and never included in CSV exports.

Cost Transparency

Twilio charges ~$0.005 per phone lookup for Line Type Intelligence. Google Places charges ~$0.032 per 20 places text search. Hard lookup caps prevent accidental overspending.

Google Maps Compliance (PRD Section 11)

Google Places API is used for real-time discovery and display. Bulk CSV lead export is restricted for Google-derived records. To export leads, use Provider B (Licensed Dataset) or Demo Mode.

No Keys? Use Demo Mode

Switch to Demo Mode on the New Scan page to test the entire interface and export synthetic Comcast records without any accounts or API keys.
